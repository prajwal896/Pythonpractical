# Python Practical

A collection of small Python exercises from practical assignments, organized into two sets.

## Stack

- **Language:** Python 3
- No external dependencies — everything runs with a standard Python install.

## Structure

```
Pythonpractical/
├── setA/
│   ├── ex5setAQ1.py   # Function to add two numbers
│   ├── ex5setAQ2.py   # Check if a number is even or odd
│   ├── ex5setAQ3.py   # Square of a number using a lambda
│   ├── ex5setAQ4.py   # Function with a default argument
│   └── ex5setAQ5.py   # Square root using the math module
└── setB/
    ├── ex5setbQ1.py   # Check if a number is prime
    ├── ex5setq2.py    # (in progress)
    ├── ex5setBQ3.py   # (in progress)
    ├── ex5setq4.py    # Factorial using recursion
    └── ex5setqQ5.py   # (in progress)
```

## Running

Each file is standalone. Run any of them directly:

```bash
python setA/ex5setAQ1.py
python setB/ex5setbQ1.py
```

Some scripts (e.g. `ex5setAQ2.py`, `ex5setAQ5.py`, `ex5setbQ1.py`) prompt for input via the terminal, so run them interactively rather than piping input.

## Notes

A few files in `setB` (`ex5setq2.py`, `ex5setBQ3.py`, `ex5setqQ5.py`) are currently empty/incomplete — work in progress.
